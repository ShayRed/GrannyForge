## Was kann das Tool?

Viele GR2-Modelle haben Logos, Schriftzüge, Extra-Meshes oder Müll dran. Mit GrannyForge siehst du das Modell **live** und löschst genau das, was weg soll — ohne 3ds Max / Blender.

- 3D-Vorschau mit Texturen (DDS / TGA / PNG)
- Einzelne Teile anklicken (Buchstaben, Schwanz, Rüstungsteil …) und entfernen
- Ganze Meshes oder Animationen löschen
- Speichern als normale `.gr2` (Rest bleibt intakt)
- Eingebauter Updater (neue Versionen vom Release)

## Bedienung (kurz)

1. `GrannyForge.exe` starten  
2. `.gr2` reinziehen oder **Öffnen…**  
3. Rechts in der Vorschau Teil anklicken (wird rot)  
4. **Teile entfernen** — oder Tab **Teile** links nutzen  
5. **Speichern unter…**

| Maus | Aktion |
| --- | --- |
| Ziehen | Drehen |
| Rad | Zoomen |
| Mittelklick / Shift+Ziehen | Schwenken |
| Klick auf Modell | Teil markieren |
| **Teile färben** | zeigt, was einzeln anklickbar ist |

Änderungen gelten erst nach dem Speichern. **Neu laden** verwirft ungespeichertes.
