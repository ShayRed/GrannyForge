## Features

Many Metin2 GR2 models come with logos, letters, extra meshes, or junk you don’t want. GrannyForge shows the model **live** so you can remove exactly what you need — without 3ds Max or Blender.

- Textured 3D preview (DDS / TGA / PNG)
- Click individual parts (letters, tails, armor pieces, …) and delete them
- Remove whole meshes or animations
- Load sibling animation GR2s and play them in the preview
- Replace a selected part’s texture (PNG / DDS / TGA)
- Save as a normal `.gr2` (everything else stays intact)
- Built-in update check from GitHub Releases
- UI language: **English** (default) or **German** in Settings

## Quick start

1. Start `GrannyForge.exe`
2. Drop a `.gr2` into the window, or use **Open…**
3. In the preview (right), click a part (it turns red)
4. Click **Remove parts** — or use the **Parts** tab
5. **Save as…**

| Mouse | Action |
| --- | --- |
| Drag | Rotate |
| Wheel | Zoom |
| Middle-click / Shift+drag | Pan |
| Click model | Select part |
| **Color parts** | Shows what can be clicked separately |

Changes are written only when you save. **Reload** discards unsaved work.
